# E-Commerce Sales Analysis

## Project Overview
This project analyzes e-commerce sales data to understand sales performance, customer behavior, orders, products, payments, and returns.

## Tools Used
- SQL Server
- Power BI
- Excel / CSV
- DAX

## Analysis Performed
- Total Sales
- Total Orders
- Total Customers
- Total Products
- Total Returns
- Sales by Shipping City
- Sales by Product Category
- Orders by Status
- Sales by Payment Method
- Quantity by Category
- Returns by Reason

## Dashboard
The Power BI dashboard provides an interactive view of e-commerce sales and performance.

## Skills Demonstrated
- SQL querying
- Data cleaning and analysis
- Data modeling
- Power BI dashboard development
- Data visualization
- Business insights
